# Security Policy

## Reporting Security Issues

If you discover a security vulnerability within `watermill-coordinator`, please report it via private vulnerability reporting:

- Submit a report through GitHub [Private Vulnerability Reporting](https://github.com/magnusp/watermill-coordinator/security/advisories/new)
- Or email security concerns directly to the project maintainer.

Please do not disclose security issues in public issue trackers or pull requests until a fix and advisory have been published.
